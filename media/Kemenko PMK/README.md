# 🖼️ Kemenko PMK Information Security Infographic

## 📌 Project Overview

This project involved designing an internal visual campaign titled *"Amankan Aset, Lindungi Privasi"* for *Kementerian Koordinator Bidang Pembangunan Manusia dan Kebudayaan RI (Kemenko PMK)*, aimed at promoting information security protocols and data protection awareness within the ministry. 
The infographic translates essential cybersecurity best practices—such as device security and privacy maintenance—into an engaging and easily digestible visual format for institutional staff.

## 👤 My Role

- Visual design and layout creation
- Translating technical cybersecurity protocols into clear, accessible visual information
- Content structuring for an internal awareness campaign
